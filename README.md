# Off We Go — clickable prototype

A no-API, clickable prototype of Off We Go, a family trip planner. Walk from a trip idea to a trip detail page without any API keys.

Live: https://lujin88.github.io/off-we-go-clickable-prototype/

Built from the `prototype/clickable-no-api` branch of the private Off-We-Go repo. Static files only; open `index.html` or serve the folder.
